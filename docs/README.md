- ⚡ **Up to 50x leverage** - Maximize your trading potential
- 💰 **Low fees** - 0.045% maker/taker + 0.03% builder fee
- 🌐 **Global access** - Trade from anywhere, 24/7

- **Frontend**: Next.js 16, React 19, TypeScript
